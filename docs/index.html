METHODOLOGY

Designed for decisions, not backtest promises.

Three risk estimates reveal model disagreement. Historical forecasting errors inform a risk margin. Every allocation exposes the trade-off between risk protection and expected return.

from portfolio_risk_lab import PortfolioAnalyzer

lab = PortfolioAnalyzer(
    returns,
    cash_asset="Cash_Proxy",
    risk_budget=0.12,
    max_weight=0.40
)
result = lab.compare(
    methods=["standard", "scenario_robust"],
    uncertainty="historical_calibration"
)
print(result.risk_budget_analysis)
